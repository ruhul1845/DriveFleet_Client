# DriveFleet Client

Live Site URL: Add your deployed Vercel URL here.

## Features
- Modern full-stack car rental UI built with Next.js and Tailwind CSS.
- Better Auth email/password authentication with optional Google login setup.
- Explore cars with database-powered cards, search by car name, and filter by car type.
- Private pages for Add Car, My Bookings, and My Added Cars.
- Booking modal, update/delete listing controls, loading spinner, and custom 404 page.
- Responsive layout for mobile, tablet, and desktop.

## Run Locally
```bash
npm install
npm run dev
```

Create `.env.local` from the provided sample values and run the server on port 5000.
